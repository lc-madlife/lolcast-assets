# lolcast-assets

LOLCAST 채팅 이펙트에 쓰는 무료 에셋입니다. 출처와 라이선스가 확실한 파일만 둡니다.

## effects/

| 파일 | 원본 | 만든 사람 | 라이선스 |
|---|---|---|---|
| `christmas-santa-tree.lottie` | [Christmas tree with Santa hide](https://lottiefiles.com/free-animation/christmas-tree-with-santa-hide-lJ4XoVYqTF) | Doodly | [Lottie Simple License](LICENSE.md) |
| `christmas-tree-snowman.lottie` | [Christmas tree with snowman](https://lottiefiles.com/free-animation/christmas-tree-with-snowman-sIOgAahA09) | Rumana | [Lottie Simple License](LICENSE.md) |

이 애니메이션들은 Lottie Simple License(LICENSE.md)를 따릅니다. 고친 파일도 같은 라이선스로 배포합니다.

## effects/christmas-choak/

크리스마스콘 이펙트(7초, 30fps, 투명 배경). 초악 산타가 썰매를 타고 지나가며 초악8(분홍 옷, 머리 위 하트)로 지나갑니다.

| 파일 | 캔버스 | 비고 |
|---|---|---|
| `christmas-choak.json` · `.lottie` | 1280 × 720 | 가로 화면 |
| `christmas-choak-portrait.json` · `.lottie` | 720 × 1280 | 세로 화면 |
| `poses.png` | — | 포즈 미리 보기 |

- 그림·움직임: LOLCAST 를 위해 새로 그린 것. 초악은 LOLCAST 운영자의 캐릭터입니다.
- 인사말 글자는 Lobster Two 서체의 윤곽선입니다(SIL Open Font License, `Lobster-Two-OFL.txt`).
- 위 표의 Lottie Simple License 는 이 폴더에 해당하지 않습니다.

## effects/newyear-choak/

새해콘 이펙트(7초, 30fps, 투명 배경). 초악이 3·2·1 을 센 뒤 안경에서 민트색 빔을 쏘고, 불꽃놀이 아래에서 인사합니다.

| 파일 | 캔버스 | 비고 |
|---|---|---|
| `newyear-choak.json` · `.lottie` | 1280 × 720 | 가로 화면 |
| `newyear-choak-portrait.json` · `.lottie` | 720 × 1280 | 세로 화면 |
| `poses.png` | — | 포즈 미리 보기 |

- 새로 그린 도형·움직임은 CC0 1.0(`CC0-1.0.txt`). 초악은 LOLCAST 운영자의 캐릭터입니다.
- 인사말 글자는 Berkshire Swash 서체의 윤곽선입니다(SIL Open Font License, `Berkshire-Swash-OFL.txt`).
